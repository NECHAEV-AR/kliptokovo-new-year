# Ледяное проклятие Клиптоково

Статический адаптивный сайт для новогодней активности KlipTok.

## Локальный запуск
Откройте `index.html` в браузере. Для разработки можно использовать расширение Live Server в VS Code.

## Публикация на GitHub Pages
1. Загрузите все файлы и папку `assets` в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через несколько минут GitHub покажет адрес опубликованного сайта.

## Текущий статус
Это первая фронтенд-версия: адаптивная главная страница, история, этапы, амулеты, жетоны и правила. Данные амулетов/жетонов пока представлены информационными заглушками.

## Следующие этапы разработки
- Страницы с заданиями каждого этапа и карточки заданий.
- Админ-панель для управления заданиями.
- Авторизация организаторов и серверное хранение данных.
- Подключение приватных Google Sheets через защищённый backend.

**Важно:** GitHub Pages размещает статические файлы. Настоящая защищённая админ-панель, отложенная публикация и приватная интеграция с Google Sheets потребуют backend. Не размещайте ключи API или пароли в HTML/JavaScript.
